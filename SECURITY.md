# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/micknorj/Rimmile/security/advisories/new), if available.

If private reporting is unavailable, open a general issue requesting a secure contact method **without** sharing exploit instructions or sensitive information.

Include a concise description, the affected area, steps to reproduce, and the potential impact. Remove any credentials, private links, personal information, or proprietary files before submitting a report.

## Responsible Disclosure

Please allow time to investigate and address an issue before disclosing exploit details publicly. For vulnerabilities in third-party software, consider reporting them to the relevant upstream maintainers as well.
