# Rimmile

Rimmile is a browser-based driving experience focused on exploration and atmosphere. Enjoy an endless nighttime drive through mountain roads, forests, and rivers—no destination, no time limit, just the road. Part of **Mick's Lab**.

## Controls

| Action | Default keys |
| --- | --- |
| Accelerate | `W` / `↑` |
| Brake | `S` / `↓` |
| Steer | `A` / `D` or `←` / `→` |
| Shift (manual) | `Q` / `E` |
| Select Drive / Reverse (near a stop) | `R` |
| Return to the road | `T` |
| Toggle lights | `L` |
| Pause | `Esc` |

Use the accelerator to move in Reverse. Key bindings can be changed in Settings.

## Requirements

A desktop browser with WebGL2 support is required. Performance varies by device and graphics settings.

## Privacy

Rimmile does not require an account or include in-game analytics. Preferences and total distance are stored locally in your browser. Hosting providers may process routine connection data when serving the game.
